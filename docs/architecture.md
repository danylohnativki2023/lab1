# Архітектура AI-агента

## Проблеми, які вирішує агент
Агент автоматизує рутинні задачі з налаштування Python-проєкту, усуваючи людський фактор при ізоляції залежностей (`venv`), написанні базових тестів (`pytest`) та налаштуванні матриці CI/CD для трьох операційних систем.

## Skills (Навички)
- `project-scaffold`: генерує базовий код та `.gitignore`.
- `build-and-test`: налаштовує систему тестування `pytest` та віртуальне середовище.
- `github-actions`: генерує файл `.github/workflows/ci.yml`.

## Commands (Команди)
Доступні команди користувача: `git-init`, `create-project`, `create-build`, `create-actions`, `check`.

## Потік даних та обробка помилок
Оркестратор (команда `init`) послідовно викликає окремі команди. Результат роботи кожної команди (наявність файлів, успішний код повернення тестів) перевіряється перед запуском наступної. У разі виникнення помилки оркестратор зупиняє виконання сценарію.
