## Project Description
This project demonstrates an AI agent for automatically generating a cross-platform Python Hello World application. The agent scaffolds the structure, configures a virtual environment, writes tests, and generates a CI/CD pipeline.

## Local Execution
1. Create a virtual environment:
   `python3 -m venv .venv`
2. Activate it:
   - Linux/macOS: `. .venv/bin/activate`
   - Windows: `.venv\Scripts\activate`
3. Install dependencies:
   `python -m pip install -r requirements.txt`
4. Run tests:
   `python -m pytest -q`
